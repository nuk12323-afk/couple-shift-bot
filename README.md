# ระบบตารางเวรคู่รัก 💕 (Couple Shift Schedule with LINE & Typhoon OCR)

ระบบจัดการตารางเวรสำหรับคู่รักที่มีกะการทำงานไม่ตรงกัน (เช่น พยาบาล, แพทย์, เจ้าหน้าที่โรงพยาบาล, งานกะโรงงาน ฯลฯ) พร้อมระบบอ่านตารางเวรภาษาไทยอัตโนมัติด้วย **Typhoon OCR (SCB 10X)** และแจ้งเตือนผ่าน **LINE Messaging API ทุกวันเวลา 07:30 น.**

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **⏰ แจ้งเตือนสรุปเวรทุกวันเวลา 07:30 น.**
   - ส่งข้อความ **LINE Flex Message** อัตโนมัติทุกเช้า
   - แจ้งกะเวรของทั้งคุณและแฟน (เช้า/บ่าย/ดึก/Off) พร้อมเวลาเริ่ม-สิ้นสุด
   - แสดงสถานะพิเศษ เช่น *"🎉 วันนี้วันหยุดตรงกันทั้งคู่! ไปเที่ยวไหนดีนะ 💕"* หรือ *"☀️ วันนี้เข้าเวรพร้อมกัน สู้ๆ นะคะ ✌️"*
2. **⚡ ถ่ายรูปตารางเวรให้อ่านอัตโนมัติด้วย Typhoon OCR (SCB 10X)**
   - รองรับทั้งไฟล์รูปภาพ (PNG, JPG, WEBP) และไฟล์เอกสาร PDF
   - โมเดล **Typhoon OCR (`typhoon-ocr`)** อ่านภาษาไทย หัวตาราง และรหัสเวร (ช, บ, ด, Off, 24 ชม.) ได้แม่นยำสูง
   - มีระบบ AI สกัดชื่อและวันที่ออกมาเป็นตารางให้ตรวจทานก่อนกดบันทึกลงปฏิทิน
3. **📅 ปฏิทินตารางเวรคู่รัก (Dual Calendar View)**
   - หน้าเว็บสวยงาม ใช้งานง่ายทั้งบนมือถือ (Responsive / LIFF App) และคอมพิวเตอร์
   - แสดงเวรคู่กันในแต่ละวัน แยกสีตามบุคคล
   - ระบบไฮไลท์ **"วันว่างตรงกัน" (Free Days)** เพื่อช่วยวางแผนไปเดทหรือไปเที่ยวล่วงหน้า
   - สามารถคลิกที่วันเพื่อแก้ไขเวรได้ทันที
4. **🤖 LINE Bot Assistant**
   - ส่งรูปตารางเวรเข้ามาในห้องแชท LINE เพื่อให้บอทอ่านตารางเวรได้เลยทันที
   - คำสั่งแชทด่วน:
     - `เวรวันนี้` → ดูตารางเวรวันนี้
     - `เวรพรุ่งนี้` → ดูตารางเวรวันพรุ่งนี้
     - `วันว่าง` → แสดงรายชื่อวันที่หยุดตรงกันในเดือนนี้
     - `ช่วยเหลือ` → ดูคู่มือการใช้งาน

## 🚀 วิธีเริ่มต้นใช้งาน (Quick Start)

### 1. เปิดโปรแกรม
ดับเบิลคลิกที่ไฟล์:
```
start.bat
```
หรือรันผ่าน Terminal:
```powershell
.venv\Scripts\python run.py
```

### 2. เข้าใช้งานระบบ
- **หน้าเว็บปฏิทิน / แดชบอร์ด**: [http://localhost:8000](http://localhost:8000)
- **LINE Webhook URL**: `http://<your-domain-or-ngrok>/api/line/webhook`

---

## ⚙️ การตั้งค่าระบบ (`.env`)

เปิดไฟล์ `.env` และกรอกข้อมูลต่อไปนี้:

```env
# LINE Messaging API (สมัครและคัดลอกจาก https://developers.line.biz)
LINE_CHANNEL_ACCESS_TOKEN="YOUR_LINE_CHANNEL_ACCESS_TOKEN"
LINE_CHANNEL_SECRET="YOUR_LINE_CHANNEL_SECRET"

# Typhoon API Key (สมัครรับ Key ฟรีที่ https://opentyphoon.ai)
TYPHOON_API_KEY="YOUR_TYPHOON_API_KEY"

# เวลาแจ้งเตือนประจำวัน (ตั้งไว้ที่ 07:30 น.)
DAILY_REMINDER_TIME="07:30"
TIMEZONE="Asia/Bangkok"

# ชื่อของคุณและแฟน (ตั้งให้ตรงกับในใบตารางเวรเพื่อให้ OCR จับคู่ถูก)
USER1_NAME="ฉัน"
USER2_NAME="แฟน"
```

> **ทิป**: เมื่อทักแชทหาบอท หรือดึงบอทเข้ากลุ่ม 2 คน ระบบจะจดจำ `TARGET_LINE_ID` ให้อัตโนมัติ

## 📁 โครงสร้างโปรเจกต์

```
├── .env                  # การตั้งค่า API Keys และเวลาแจ้งเตือน
├── .env.example          # ตัวอย่างไฟล์ตั้งค่า
├── config.py             # จัดการการโหลดค่า Config
├── database.py           # เชื่อมต่อ SQLite และค่าเริ่มต้น
├── models.py             # โครงสร้างฐานข้อมูล (Person, Shift, ShiftType, SystemSetting)
├── main.py               # FastAPI Server, Webhook & API Routes
├── run.py                # ตัวเปิดเซิร์ฟเวอร์
├── start.bat             # ทางลัดเปิดโปรแกรมสำหรับ Windows
├── test_shifts.py        # ชุดทดสอบระบบ
├── services/
│   ├── typhoon_service.py # โมดูลประมวลผล Typhoon OCR และสกัดข้อมูลเวร
│   ├── line_service.py    # โมดูลสร้าง Flex Message และส่งข้อความ LINE
│   └── scheduler.py       # ระบบตั้งเวลาส่งข้อความอัตโนมัติ (07:30 น.)
└── static/
    └── index.html         # หน้าเว็บแอปปฏิทินคู่รัก + โมดัลอัปโหลด OCR
```
